# ไปวัด 3D

นั่งในพระอุโบสถแบบสามมิติ หันมองรอบตัว และฟังพระสงฆ์ 5 รูปสวดมนต์ตรงหน้า
สร้างด้วย Next.js + three.js (React Three Fiber)

```bash
npm install
npm run dev     # http://localhost:3000
```

## การควบคุม

- ลากเมาส์ / นิ้ว หรือปุ่มลูกศร (A/D/W/S) เพื่อหันมอง
- ล้อเมาส์เพื่อซูม
- ปุ่ม "กราบพระ" กล้องจะก้มกราบ 3 ครั้ง

## เสียงสวด

สลับได้ที่ปุ่มมุมขวาบน ทั้งสองแบบมาจากตำแหน่งพระ (HRTF) ใส่หูฟังแล้วหันหัว เสียงจะย้ายข้างตาม

- **เสียงจริง** (ค่าเริ่มต้น): `public/audio/chant.mp3` พระปาติโมกข์ บันทึกที่วัดคุ้งตะเภา จ.อุตรดิตถ์
  โดย พระวินัยธร จาก [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Bhikkhu_P%C4%81%E1%B9%ADimokkha_Pali.ogg)
  สัญญาอนุญาต [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) (ดัดแปลง: ตัด 8 นาทีแรก ลดเสียงรบกวน ปรับระดับเสียง)
- **บทสวด+คำอ่าน**: สังเคราะห์สดในเบราว์เซอร์ (formant synthesis) นะโม ×3, พุทธคุณ, ธรรมคุณ, สังฆคุณ
  พร้อมคำบรรยายไฮไลต์ทีละคำ

จะใช้เสียงสวดของตัวเองก็ได้: แทนที่ `public/audio/chant.mp3` แล้วแก้เครดิตใน `src/lib/audio/recording.ts`
ถ้าโหลดไฟล์ไม่ได้ ระบบจะใช้เสียงสังเคราะห์ให้อัตโนมัติ

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/components/TempleExperience.tsx` | หน้าแรก, แถบปุ่ม, คำบรรยายบทสวด |
| `src/components/TempleScene.tsx` | Canvas, แสง, post-processing |
| `src/components/scene/*` | โบสถ์, พระประธาน, พระสงฆ์, เทียน/ธูป, แสงแดด, การหันกล้อง |
| `src/lib/audio/engine.ts` | เสียงสวดสังเคราะห์, ระฆัง, เสียงก้อง, นก |
| `src/lib/audio/chants.ts` | บทสวด (ไทย + โรมันสำหรับสังเคราะห์) |
| `src/lib/textures.ts` | ลายไทยวาดด้วย canvas (ลายรดน้ำ, ประจำยาม, ต้นโพธิ์, ดาวเพดาน) |
