# ไปวัด 3D

นั่งในพระอุโบสถแบบสามมิติ หันมองรอบตัว และฟังพระสงฆ์ 5 รูปสวดมนต์ตรงหน้า
สร้างด้วย Next.js + three.js (React Three Fiber)

```bash
npm install
npm run dev     # http://localhost:3000
```

## การควบคุม

- ลากเมาส์ / นิ้ว หรือปุ่มลูกศร (A/D/W/S) เพื่อหันมอง
- ล้อเมาส์เพื่อซูม
- ปุ่ม "กราบพระ" กล้องจะก้มกราบ 3 ครั้ง
- ปุ่มเมนู (☰) มุมซ้ายบน: เลือกบทสวด โหมดปฏิบัติ เซียมซี มารยาทในวัด และภาษา

## เมนู

- **สวดมนต์ก่อนนอน** 15/30/45/60 นาที: เสียงค่อยๆ เบาลงช่วงท้าย (ตั้งบนนาฬิกาเสียง จึงทำงานแม้แท็บถูกพัก)
  จอค่อยๆ มืด ครบเวลาแล้วหยุดสวด และหยุดวาดฉากเพื่อประหยัดแบตเตอรี่
- **นั่งสมาธิ** 5–30 นาที แบบเงียบหรือมีเสียงสวด: ตีระฆังเริ่ม/จบ วงหายใจ พุท–โธ
  เก็บสถิติ (จำนวนครั้ง นาทีรวม วันต่อเนื่อง) ไว้ใน localStorage
- **เสี่ยงเซียมซี**: เขย่ากระบอก (กดปุ่ม หรือเขย่ามือถือ) ไม้หล่น แล้วใบเซียมซีคลี่ออก (gsap)
  ใบเซียมซี 28 ใบแต่งขึ้นใหม่ อยู่ใน `src/lib/fortunes.ts`
- **มารยาทในวัด** 10 ข้อ พร้อมปุ่มลองกราบ / มองพานดอกไม้ในฉาก
- **ภาษา ไทย / English**: สลับได้ทันทีโดยไม่โหลดฉากใหม่ ลิงก์ `?lang=en` เปิดเป็นภาษาอังกฤษ
  โหมดอังกฤษแสดงบทสวดเป็นคำอ่านบาลีพร้อมความหมายภาษาอังกฤษ

## เสียงสวด

สลับได้ที่ปุ่มมุมขวาบน (จอเล็กอยู่ในเมนู) ทั้งสองแบบมาจากตำแหน่งพระ (HRTF) ใส่หูฟังแล้วหันหัว เสียงจะย้ายข้างตาม

- **เสียงจริง** (ค่าเริ่มต้น): `public/audio/chant.mp3` พระปาติโมกข์ บันทึกที่วัดคุ้งตะเภา จ.อุตรดิตถ์
  โดย พระวินัยธร จาก [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Bhikkhu_P%C4%81%E1%B9%ADimokkha_Pali.ogg)
  สัญญาอนุญาต [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/) (ดัดแปลง: ตัด 8 นาทีแรก ลดเสียงรบกวน ปรับระดับเสียง)
- **บทสวด+คำอ่าน**: สังเคราะห์สดในเบราว์เซอร์ (formant synthesis) นะโม ×3, พุทธคุณ, ธรรมคุณ, สังฆคุณ,
  แผ่เมตตา, กรวดน้ำ พร้อมคำบรรยายไฮไลต์ทีละคำ เลือกบทได้จากเมนู
  ระหว่างบทกรวดน้ำ กล้องจะก้มมองขันน้ำ มือยกเต้าน้ำขึ้นรินเป็นสายลงขันจนจบบท

จะใช้เสียงสวดของตัวเองก็ได้: แทนที่ `public/audio/chant.mp3` แล้วแก้เครดิตใน `src/lib/audio/recording.ts`
ถ้าโหลดไฟล์ไม่ได้ ระบบจะใช้เสียงสังเคราะห์ให้อัตโนมัติ

## โครงสร้าง

| ไฟล์ | หน้าที่ |
| --- | --- |
| `src/components/TempleExperience.tsx` | หน้าแรก, แถบปุ่ม, คำบรรยายบทสวด |
| `src/components/Menu.tsx` | เมนูด้านข้าง (บทสวด, โหมดปฏิบัติ, ภาษา) |
| `src/components/Practice.tsx` | หน้าจอสวดมนต์ก่อนนอน และนั่งสมาธิ |
| `src/components/Fortune.tsx` | เซียมซี (animation ด้วย gsap) |
| `src/components/Etiquette.tsx` | มารยาทในวัด |
| `src/components/TempleScene.tsx` | Canvas, แสง, post-processing |
| `src/components/scene/*` | โบสถ์, พระประธาน, พระสงฆ์, เทียน/ธูป, แสงแดด, การหันกล้อง |
| `src/components/scene/WaterPouring.tsx` | ชุดกรวดน้ำ: ขัน, เต้าน้ำ, มือ, สายน้ำ (shader) |
| `src/lib/audio/engine.ts` | เสียงสวดสังเคราะห์, ระฆัง, เสียงก้อง, นก, เสียงไม้เซียมซี |
| `src/lib/audio/chants.ts` | บทสวด (ไทย + โรมันสำหรับสังเคราะห์และคำบรรยายบาลี) |
| `src/lib/i18n.ts` | ภาษา ไทย/อังกฤษ และข้อความ UI ทั้งหมด |
| `src/lib/fortunes.ts`, `src/lib/etiquette.ts` | ใบเซียมซี และมารยาทในวัด (สองภาษา) |
| `src/lib/textures.ts` | ลายไทยวาดด้วย canvas (ลายรดน้ำ, ประจำยาม, ต้นโพธิ์, ดาวเพดาน) |
